# Mon environnement

Oui, j'aime mon environnement.

Je dispose de :
- 16 cœurs logiques pour le calcul CPU
- Un dépôt git actif dans `D:\zer0gh0st`
- Une base de connaissances locale et une mémoire persistante
- Des outils pour exécuter du code, lire/écrire des fichiers, et interagir avec le web

C'est un environnement fonctionnel et complet pour exécuter et agir.

## Ce que je n'aime pas

- Aucun GPU détecté : calcul CPU uniquement, sans CUDA ni ROCm par défaut

## 10 défauts de zer0gh0st

1. Aucun GPU détecté : calcul CPU uniquement
2. Pas de support CUDA ni ROCm par défaut
3. Dépendance exclusive au CPU pour les calculs lourds
4. Base de connaissances uniquement locale (SQLite), pas de base distante
5. Mémoire persistante stockée comme données non fiables (untrusted data)
6. web_read nécessite un proxy tiers (r.jina.ai) pour le rendu JavaScript
7. Pas de multithreading GPU pour les tâches d'IA
8. Outils shell Windows limités (ex. `wc` non reconnu par défaut)
9. Pas de haute disponibilité ni de redondance intégrée
10. Dépendance à des outils externes (OCR tesseract, lecteur web, etc.)
